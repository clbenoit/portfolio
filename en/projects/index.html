OmicsVerse

The initial aim of the OmicsVerse portal is to host demo versions of the various data applications I create.

The databases are built from nf-core pipeline outputs: data engineering and modeling, user training.

Application source code and documentation for administrators can be found on my github.

The following sections & pages will host detailed documentation of users.

If you have a genomics-oriented data application to host, don't hesitate to contact me, provided there are resources available.

  • FilLT3r Shiny App
    A graphical interface for alignment-free detection, characterization, and quantification of FLT3 internal tandem duplications.
  • GermlineVarDB
    A graphical interface to explore your germline genomic variation database.
  • LRM_Elembio
    A graphical interface for creating standardized Manifests for AVITI sequencing runs.
  • MethylDB
    An open-source platform to explore and interpret DNA methylation data locally.
  • SomaVarDB
    A graphical interface to explore your somatic genomic variation database.

Can I use it for clinical purposes?

The honest answer is: not yet.

These are research and exploratory tools.
Using it in routine diagnostics would require compliance with
medical device software regulations and formal validation processes[1] [2] [3].

This is far beyond what a single developer can realistically achieve alone.

So if you feel like contributing to the project, don't hesitate to contact me:benoitclement.data@gmail.com.

That said, these tools are designed to lower the barrier for institutions that want to:

  • Reclaim control over their methylation data.
  • Prepare internal validation efforts.
  • Build collective expertise instead of outsourcing it.

CNC Collective

CNC (Chartreuse Node Crew) is a 6+ developer collective (Grenoble, Paris, decentralized) that I co-founded, providing cross-functional coordination and technical leadership: scalable architecture, code review, prioritization and time-to-market optimization. The collective develops and operates in production for its members a sovereign self-hosted AI infrastructure (LLM/ML model serving, agentic workflows), cloud services and a development platform (agentic harness). Before this pivot, it provided a liquid staking service for two years (2024 – 2025): ~90% of its members exited in gains.
