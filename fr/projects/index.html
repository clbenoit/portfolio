Voici mes projets

OmicsVerse

L'objectif initial du portail OmicsVerse est d'héberger des versions de démonstration des différentes applications de données que je crée.

Les bases de données sont construites à partir des sorties de pipelines nf-core : ingénierie et modélisation de la donnée, formation des utilisateurs.

Le code source des applications et la documentation pour les administrateurs sont disponibles sur mon github.

Les sections et pages suivantes hébergeront la documentation détaillée pour les utilisateurs.

Si vous avez une application de données à orientation génomique à héberger, n'hésitez pas à me contacter, sous réserve de ressources disponibles.

  • Application Shiny FilLT3r
    Interface graphique pour la détection, la caractérisation et la quantification sans alignement des duplications FLT3-ITD.
  • GermlineVarDB
    Interface graphique pour explorer votre base de données de variations génomiques germinales.
  • LRM_Elembio
    Interface graphique pour créer des Manifests standardisés pour les runs de séquençage AVITI.
  • MethylDB
    Plateforme open-source pour explorer et interpréter les données de méthylation de l'ADN localement.
  • SomaVarDB
    Interface graphique pour explorer votre base de données de variations génomiques somatiques.

Puis-je l'utiliser à des fins cliniques ?

La réponse honnête est : pas encore.

Ce sont des outils de recherche et d'exploration.
Les utiliser en diagnostic de routine nécessiterait une conformité
aux réglementations sur les dispositifs médicaux logiciels et des processus de validation formels[1] [2] [3].

C'est bien au-delà de ce qu'un seul développeur peut réaliser de manière réaliste seul.

Donc si vous souhaitez contribuer au projet, n'hésitez pas à me contacter :benoitclement.data@gmail.com.

Cela dit, ces outils sont conçus pour abaisser la barrière pour les institutions qui souhaitent :

  • Reprendre le contrôle de leurs données de méthylation.
  • Préparer des efforts de validation interne.
  • Développer une expertise collective plutôt que de l'externaliser.

CNC Collective

CNC (Chartreuse Node Crew) est un collectif de 6+ développeurs (Grenoble, Paris, décentralisé) que je cofonde, avec coordination transverse et leadership technique : architecture scalable, revue de code, priorisation et optimisation du time-to-market. Le collectif développe et opère en production pour ses membres une infrastructure IA self-hosted souveraine (serving de modèles LLM/ML, workflows agentiques), des services cloud et une plateforme de développement (harness agentique). Avant ce pivot, il a fourni pendant deux ans (2024 – 2025) un service de liquid staking : ~90 % des membres en sont sortis en gains.

  • CNC Collective
    Infrastructure IA self-hosted souveraine, services cloud & développement agentique d'un collectif de 6+ développeurs.
